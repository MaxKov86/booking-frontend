# Booking Frontend

Next.js (App Router) + TypeScript + Tailwind + TanStack Query + Zustand фронтенд для booking-системи. Працює у парі з окремим репозиторієм [`booking-backend`](../booking-backend) (Express + MongoDB).

## Запуск

Спочатку має бути запущений бекенд (за замовчуванням на `:4000`).

```bash
npm install
cp .env.example .env.local
npm run dev
```

Фронтенд стартує на `http://localhost:3000`.

Щоб перевірити: створи спеціаліста через бекенд (`POST /api/auth/register`), налаштуй йому розклад (`PUT /api/availability/:userId`), потім введи його `userId` на головній сторінці — і потрапиш на `/book/:userId`.

## Архітектура

**Типи домену свідомо продубльовані** з бекенду (`features/booking/types.ts`), а не витягнуті зі спільного пакета — фронтенд і бекенд це два окремі репозиторії. Для проекту такого розміру shared-пакет додав би monorepo-тулінг, який ускладнює запуск і деплой більше, ніж економить на дублюванні кількох інтерфейсів.

**`apiClient.ts`** — обгортка над `fetch` з кастомним `ApiError`, який несе HTTP-статус. Це дозволяє компонентам розрізняти "мережа впала" від "409, бо слот щойно зайняли" — звичайний `Error` статусу не ніс би.

**TanStack Query** для всього серверного стану, **Zustand** — для клієнтського (з'явиться на кроці 7 для auth-стану адмінки). Той самий принцип розділення, що й у проекті 3.

## Палітра

Indigo/slate, світла тема за замовчуванням — свідомо інша, ніж у попередніх проектах портфоліо (amber/charcoal у 1-2, teal у 3). Публічна сторінка бронювання має виглядати нейтрально й довірливо для випадкового відвідувача, який лишає персональні дані.

## Структура

```
src/
  app/
    providers/       # QueryClientProvider (без MSW — реальний бекенд)
    book/[userId]/   # публічна сторінка бронювання
    page.tsx         # тимчасова стартова (ввід userId для розробки)
  features/
    booking/
      types.ts       # домен (продубльовано з бекенду)
      api.ts         # TanStack Query хуки
      components/    # DatePicker, SlotPicker, BookingFlow
    auth/            # крок 7
  shared/
    lib/apiClient.ts # fetch-обгортка + ApiError
  store/             # Zustand (крок 7)
```
